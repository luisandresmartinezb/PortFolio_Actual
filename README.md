## Responsive design

La interfaz está adaptada a distintos tamaños de pantalla:

| Dispositivo | Comportamiento |
|---|---|
| Escritorio | Distribución completa y tarjetas en varias columnas |
| Tablet | Reorganización de grids y contenidos |
| Móvil | Una columna, navegación y botones adaptados |

## Ejecutar en local

No requiere instalación de dependencias ni proceso de compilación.

1. Clona el repositorio:

```bash
git clone URL-DE-TU-REPOSITORIO.git
```

2. Entra en la carpeta:

```bash
cd NOMBRE-DEL-REPOSITORIO
```

3. Abre `index.html` en el navegador.

También puedes utilizar una extensión como **Live Server** desde Visual Studio Code.

## Despliegue con GitHub Pages

Este proyecto es un sitio estático, por lo que puede publicarse directamente mediante GitHub Pages.

En el repositorio:

1. Ve a **Settings**.
2. Entra en **Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main`.
5. Selecciona `/(root)`.
6. Pulsa **Save**.

Tras el despliegue, GitHub mostrará la URL pública del portfolio.
